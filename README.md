# Global Heaven Overseas Education Website

A modern, professional Next.js website for Global Heaven Overseas Education - a leading consultancy for studying in Germany.

## 🌟 Features

- **Modern Design**: Premium UI with smooth animations and transitions
- **Fully Responsive**: Works perfectly on all devices (mobile, tablet, desktop)
- **SEO Optimized**: Proper meta tags and semantic HTML
- **Fast Performance**: Built with Next.js 16 and optimized for speed
- **TypeScript**: Type-safe code for better development experience
- **Tailwind CSS v4**: Modern utility-first CSS framework

## 📄 Pages

1. **Home** (`/`)
   - Hero section with call-to-action
   - Statistics showcase
   - Services overview
   - Course offerings
   - Expert advisors section

2. **About Us** (`/about`)
   - Company information
   - Features and benefits
   - Teaching methodology
   - Success statistics

3. **Contact Us** (`/contact`)
   - Interactive contact form
   - Office locations (India & Germany)
   - Contact information
   - Map integration ready

4. **Our Services** (`/services`)
   - Comprehensive list of services
   - Application process details
   - Download options for service PDF

5. **Why Germany** (`/why-germany`)
   - Reasons to study in Germany
   - Education system overview
   - Statistics and facts
   - Benefits for international students

6. **Study in Germany** (`/study-in-germany`)
   - Available programs (Bachelor, Master, PhD)
   - Step-by-step application process
   - Requirements and documents
   - Timeline information

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ installed
- npm or yarn package manager

### Installation

1. Navigate to the project directory:
```bash
cd my-app
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## 🛠️ Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm start` - Start production server
- `npm run lint` - Run ESLint
